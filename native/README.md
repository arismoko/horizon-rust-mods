# native/

[`appleskin`](appleskin/) is AppleSkin for Sunrise, on Sunrise's mod API; it is the only folder here that builds with `cargo sunrise-mod` and is released from this fork (see the [repository README](../README.md)).

The other folders are the upstream project's earlier mods by Jorungandr, written for an older mod format. They are kept as they are and do not build on Sunrise.
